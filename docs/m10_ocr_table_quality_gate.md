# M10 OCR / table quality gate

M10 remains P2 unless a corpus scan shows that extraction or table preservation is a material failure source. This gate is deliberately diagnostic: it does not invoke OCR, alter PDF parsing, download a model, or change retrieval behavior.

## Inputs and command

Run it after `run_pipeline.py` over the target corpus. It reads only the local JSONL artifacts already generated by ingest:

```powershell
.\.venv\Scripts\python.exe scripts\corpus_quality_gate.py `
  --pages-path data\cleaned_pages\cleaned_pages.jsonl `
  --chunks-path data\chunks\chunks.jsonl `
  --output outputs\quality\corpus_quality_gate.json
```

The default paths are the same. `--without-chunks` is permitted for an extraction-only preliminary scan, but it cannot assess whether source tables survived into table-aware chunks.

## Decision contract

The JSON report contains the exact thresholds, summary ratios, sampled affected pages/documents, reason codes, and one of these decisions:

| Decision | Meaning |
| --- | --- |
| `PROMOTE_M10` | A sufficiently large scan crossed an extraction or table representation trigger. Review samples, then scope an OCR/table implementation separately. |
| `KEEP_M10_P2` | The inspected corpus did not show a trigger. Keep work on provenance, controlled tools, and evaluation first. |
| `INSUFFICIENT_DATA` | The local artifact is unavailable/too small for a confident decision. Acquire a representative, non-private scan result before prioritizing M10. |

Current conservative triggers are: at least 10 pages, then an empty-page ratio of 10% or more, a low-text-page ratio of 20% or more (fewer than 60 characters), replacement-character corruption on 1% or more of pages, or 15% or more of table-bearing documents lacking a table-aware chunk. They are signals for review, not automatic proof that OCR will solve the issue.

The report includes samples rather than raw PDF content so it can be retained as an ignored local artifact. Do not commit private PDFs, production `data/`, or generated outputs.

## What the gate does not measure

It does not measure visual fidelity, image-only charts, handwritten annotations, semantic table correctness, or retrieval quality. If it promotes M10, the next step is a bounded audit with reviewed page/table examples and a before/after benchmark—not a blanket OCR rewrite.
